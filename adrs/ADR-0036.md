# ADR-0036 — Validar Markdown com markdownlint-cli2

Status: Aceito

## Contexto

O projeto exige lint Markdown e ainda não possuía ferramenta configurada.

Escolha alinhada com o usuário nesta conversa. Aceitação da decisão não significa implementação concluída. Evidência do
estado anterior: `AGENTS.md`.

## Decisão

Adotar markdownlint-cli2 com configuração versionada e comando `npm run lint:md` na raiz. Validar também os planos locais
em `docs/`, sem versioná-los. Usar 120 colunas para prosa, preservando a largura de tabelas e blocos de código; permitir
títulos iguais somente sob pais diferentes, como as categorias de Keep a Changelog.

## Consequências

- Positivas: Padroniza documentação e permite gate reproduzível.
- Negativas ou limitações: Exige ajustar documentos existentes às convenções adotadas.

## Alternativas Consideradas

Não houve escolha de outra ferramenta; o usuário aprovou markdownlint após a proposta de markdownlint-cli2.
