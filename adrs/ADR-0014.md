# ADR-0014 — Expor métricas HTTP com OpenTelemetry

Status: Aceito

## Contexto

A API implementa contagem e duração de requisições e indicador de liveness.

Registro retrospectivo do commit `291a07f` (2025-11-30). O status Aceito descreve adoção observada no código, sem afirmar aprovação formal registrada na época.

Evidências: api/observability/metrics.py; api/blueprints/metrics.py; api/app.py.

## Decisão

Coletar métricas com OpenTelemetry e expor snapshots em formato Prometheus/OpenMetrics por `/metrics`.

## Consequências

- Positivas: Permite observar atividade HTTP.
- Negativas ou limitações: Mudanças nos hooks precisam evitar contagem duplicada e controlar cardinalidade das rotas.

## Alternativas Consideradas

O histórico disponível não registra outras opções avaliadas nem por que teriam sido descartadas. Não é possível reconstruir essa avaliação com segurança.
