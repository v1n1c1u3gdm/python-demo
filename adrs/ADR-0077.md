# ADR-0077 — Usar Gitea como forge local do Woodpecker

Status: Aceito

## Contexto

A composição de desenvolvimento local integra o Woodpecker a uma forge que autentica pelo Keycloak. A configuração
GitHub existente também atende fluxos fora desta composição e não deve ser alterada para criar a integração local.

## Decisão

Usar Gitea como forge exclusiva do Woodpecker na composição local. Conectar a autenticação nativa do Gitea ao realm
local do Keycloak e criar o cliente OAuth do Woodpecker por API nativa do Gitea. Manter a configuração GitHub existente
inalterada.

## Consequências

- O Woodpecker inicia seu fluxo de autorização pela forge Gitea local, que encaminha o usuário ao Keycloak.
- O segredo OAuth retornado uma única vez pela API do Gitea precisa ser persistido para reinicializações; sua ausência
  ou divergência exige falha fechada, sem rotação silenciosa.
- Esta decisão descreve apenas o ambiente local e não altera autenticação, segredos ou operação de produção.
- O redirecionamento nativo confirma o início do fluxo, não a conclusão de login no navegador.

## Alternativas Consideradas

Não há registro de avaliação histórica de outras forges locais; esta decisão registra a escolha aprovada para o ambiente
local e a preservação da configuração GitHub existente.
