# ADR-0046 — Integrar alterações na main exclusivamente por PR

Status: Aceito

## Contexto

O usuário pediu que a main não aceite push direto e que qualquer pessoa possa contribuir. O repositório público
pertence a `v1n1c1u3gdm`, atualmente seu único usuário com permissão de escrita. O agente usa um PAT dessa mesma conta.
Uma exigência inicial de revisão foi removida por solicitação explícita: o projeto é mantido individualmente e o
GitHub não permite que o autor aprove o próprio PR.

## Decisão

Exigir PR para integrar alterações à main, sem bypass, inclusive para administrador. Não exigir aprovação externa;
o mantenedor pode fazer merge manual dos próprios PRs. Manter bloqueados force push e exclusão da main.
Contribuições externas podem chegar por forks e PRs, sem conceder escrita no repositório.

As regras foram configuradas e consultadas pela API nesta sessão. Alterações de acesso devem reavaliar quem pode
fazer merge: a configuração atual não estabelece uma identidade humana distinta do PAT usado pelo agente.

## Consequências

- Positivas: Integrações passam por PR, com histórico revisável, sem bloquear o trabalho individual do mantenedor.
- Negativas ou limitações: A revisão depende do processo humano; não há gate de aprovação externa. O administrador
  pode editar as próprias regras. Contas futuras com permissão de escrita mudam quem pode aprovar ou integrar.

## Alternativas Consideradas

Exigir uma aprovação sem exceções: foi configurado inicialmente e removido pelo usuário por bloquear seus próprios
PRs. Uma identidade separada para o agente e uma exceção de revisão somente via PR foram apresentadas; não adotadas.
