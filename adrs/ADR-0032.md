# ADR-0032 — Construir a UI com Vite

Status: Aceito

## Contexto

A migração precisa substituir ou adaptar a cadeia Vue CLI.

Escolha alinhada com o usuário nesta conversa. Aceitação da decisão não significa implementação concluída. Evidência do
estado anterior: `ui/vue.config.js`.

## Decisão

Usar Vite com plugin Vue, alias @ e saída dist para o NGINX existente.

## Consequências

- Positivas: Simplifica a integração com a stack escolhida.
- Negativas ou limitações: Exige migrar HTML de entrada e variáveis de build.

## Alternativas Consideradas

Manter Vue CLI: opção apresentada ao usuário e descartada em favor de Vite.
