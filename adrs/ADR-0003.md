# ADR-0003 — Usar Vue 2 para a SPA

Status: Substituído

Substituído pelo [ADR-0031](ADR-0031.md), que registra a migração para Vue 3.

## Contexto

A interface pública consulta dados da API e navega entre páginas no navegador.

Registro retrospectivo do commit `291a07f` (2025-11-30). O status Aceito descreve adoção observada no código, sem
afirmar aprovação formal registrada na época.

Evidências: ui/package.json; ui/src/main.js; ui/src/router/index.js.

## Decisão

Implementar a SPA com Vue 2 e Vue Router.

## Consequências

- Positivas: Permite navegação no cliente e componentes reutilizáveis.
- Negativas ou limitações: Mantém dependência da cadeia de build e bibliotecas compatíveis com Vue 2.

## Alternativas Consideradas

O histórico disponível não registra outras opções avaliadas nem por que teriam sido descartadas. Não é possível
reconstruir essa avaliação com segurança.
