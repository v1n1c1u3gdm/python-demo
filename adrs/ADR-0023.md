# ADR-0023 — Exigir cobertura mínima antes de cada commit

Status: Substituído

Substituído por [ADR-0030](ADR-0030.md), após o usuário definir que o gate deve considerar exclusivamente linhas. O
texto abaixo preserva a política anterior.

## Contexto

O usuário estabeleceu um mínimo aceitável de 85% e medição obrigatória antes de commits.

Decisão explícita do usuário nesta conversa; formalizada em `AGENTS.md`. Não representa um release.

Evidências: AGENTS.md; ui/jest.config.js.

## Decisão

Medir cobertura antes de cada commit e exigir ao menos 85% por módulo e por métrica reportada, conforme `AGENTS.md`.

## Consequências

- Positivas: Cria um gate mensurável para commits.
- Negativas ou limitações: Exige ferramentas e coleta corretas; cobertura não substitui a qualidade dos cenários. A
  política não comprova que a meta já foi atingida.

## Alternativas Consideradas

Não foram registradas outras opções avaliadas pelo usuário nem razões de descarte; não há base para atribuir uma
comparação formal.
