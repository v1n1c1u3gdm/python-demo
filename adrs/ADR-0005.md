# ADR-0005 — Servir o build da SPA com NGINX

Status: Aceito

## Contexto

A UI produz arquivos estáticos e usa rotas em modo history.

Registro retrospectivo do commit `291a07f` (2025-11-30). O status Aceito descreve adoção observada no código, sem
afirmar aprovação formal registrada na época.

Evidências: Dockerfile; ui/nginx.conf.

## Decisão

Servir o build Vue por NGINX com fallback para `index.html`.

## Consequências

- Positivas: Permite entrega estática e navegação direta nas rotas.
- Negativas ou limitações: Não fornece proxy da API; URLs HTTP precisam funcionar no navegador.

## Alternativas Consideradas

O histórico disponível não registra outras opções avaliadas nem por que teriam sido descartadas. Não é possível
reconstruir essa avaliação com segurança.
