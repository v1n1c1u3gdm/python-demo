# ADR-0062 — Usar uv como fonte de verdade das dependências Python

Status: Aceito

## Contexto

A pipeline precisa instalar as dependências Python de forma reproduzível. Em 2026-10-04, o usuário aprovou migrar
para uv e preferiu essa abordagem a manter manualmente os arquivos `requirements`. A decisão descreve a fonte de
verdade aprovada; compatibilidade e integração ainda precisam ser validadas na implementação.

## Decisão

Usar `pyproject.toml` e `uv.lock` como fonte de verdade das dependências Python. Se algum consumidor exigir arquivos
`requirements`, gerá-los como exportação do lock; não manter uma lista manual paralela como fonte de dependências.

## Consequências

- Positivas: declarações e resolução ficam centralizadas no projeto e podem alimentar instalações reprodutíveis.
- Negativas ou limitações: os fluxos de desenvolvimento e CI precisarão adotar uv; suporte ao Python e às dependências
  deste repositório deve ser validado durante a implementação. Este ADR não afirma que o lockfile já existe ou é
  compatível.

## Alternativas Consideradas

Manter `requirements` como lista manual com pip-tools: o usuário preferiu migrar para uv. A aprovação não registra
avaliação de outras ferramentas de lock.
