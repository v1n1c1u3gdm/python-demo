# ADR-0029 — Manter ADRs atômicos e cumulativos

Status: Aceito

## Contexto

O usuário pediu decisões cumulativas, formato padronizado e consulta obrigatória pelos agentes.

Decisão explícita do usuário nesta conversa; formalizada em `AGENTS.md`. Não representa um release.

Evidências: AGENTS.md; adrs/.

## Decisão

Registrar uma única decisão por `adrs/ADR-NNNN.md` e consultar os registros antes de implementar. Quando houver necessidade de criar um novo ADR ou alterar o sentido de uma decisão, discutir primeiro com o usuário e registrar após alinhamento explícito. A reconstrução histórica solicitada permite documentar escolhas comprovadas.

## Consequências

- Positivas: Mantém contexto e rastreabilidade das escolhas.
- Negativas ou limitações: Exige manutenção dos status e vínculos de substituição; não permite inventar alternativas históricas.

## Alternativas Consideradas

Não foram registradas outras opções avaliadas pelo usuário nem razões de descarte; não há base para atribuir uma comparação formal.
