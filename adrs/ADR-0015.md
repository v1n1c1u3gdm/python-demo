# ADR-0015 — Permitir CORS global sem credenciais

Status: Aceito

## Contexto

API e UI são expostas em portas diferentes; a topologia implica chamadas entre origens no navegador.

Registro retrospectivo do commit `c4f0f3d` (2025-11-30). O status Aceito descreve adoção observada no código, sem afirmar aprovação formal registrada na época.

Evidências: api/app.py; api/requirements.txt.

## Decisão

Configurar Flask-CORS com origens `*` e `supports_credentials=False`.

## Consequências

- Positivas: Permite chamadas entre origens sob essa política.
- Negativas ou limitações: Não fornece autorização e requer revisão caso sejam introduzidos cookies ou restrições de origem.

O histórico disponível não registra outras opções avaliadas nem por que teriam sido descartadas. Não é possível reconstruir essa avaliação com segurança.
