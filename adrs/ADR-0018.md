# ADR-0018 — Validar tokens com chaves JWKS

Status: Aceito

## Contexto

A API recebe tokens emitidos pelo Keycloak.

Registro retrospectivo do commit `b459944` (2025-12-19). O status Aceito descreve adoção observada no código, sem
afirmar aprovação formal registrada na época.

Evidências: api/services/keycloak_client.py.

## Decisão

Resolver discovery e JWKS com cache para validar a assinatura dos JWT recebidos.

## Consequências

- Positivas: Permite validar tokens com chaves do provedor.
- Negativas ou limitações: Depende de rede/cache e da política de claims; o código atual desativa verificação de
  audience.

## Alternativas Consideradas

O histórico disponível não registra outras opções avaliadas nem por que teriam sido descartadas. Não é possível
reconstruir essa avaliação com segurança.
