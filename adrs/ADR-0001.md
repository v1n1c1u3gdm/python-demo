# ADR-0001 — Manter API e UI no mesmo repositório

Status: Aceito

## Contexto

A aplicação reúne backend e frontend que compartilham contratos HTTP.

Registro retrospectivo do commit `291a07f` (2025-11-30). O status Aceito descreve adoção observada no código, sem afirmar aprovação formal registrada na época.

Evidências: api/app.py; ui/package.json.

## Decisão

Manter os módulos `api/` e `ui/` no mesmo repositório, com responsabilidades separadas.

## Consequências

- Positivas: Permite coordenar alterações de contrato em uma entrega.
- Negativas ou limitações: Exige controlar o escopo entre módulos e validar consumidores.

## Alternativas Consideradas

O histórico disponível não registra outras opções avaliadas nem por que teriam sido descartadas. Não é possível reconstruir essa avaliação com segurança.
