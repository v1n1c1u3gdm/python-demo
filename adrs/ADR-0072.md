# ADR-0072: Usar MariaDB 11.4 somente para fixture BookStack nova

Status: Aceito

## Contexto

A documentação atual do BookStack requer MariaDB 10.6 ou superior. Existe uma origem potencial em MariaDB 10.5, mas sua
compatibilidade com a versão atual do BookStack não foi comprovada e nenhum dado real deve ser importado nesta tarefa.

## Decisão

Fixar MariaDB 11.4.13 para a fixture BookStack sintética e recém-criada. Não tratar esse serviço como upgrade, destino de
migração ou confirmação de compatibilidade para uma origem MariaDB 10.5.

## Consequências

- A fixture atende ao requisito mínimo publicado pelo BookStack.
- Persistência e recuperação podem ser exercitadas com dados sintéticos sem envolver bancos de origem.
- Qualquer migração futura requer avaliação própria da versão de origem, backup e compatibilidade antes de importar.

## Alternativas Consideradas

A avaliação de outras versões não foi registrada. A versão fixada foi escolhida para exceder o mínimo publicado; nenhuma
alternativa foi documentada como validada para os dados de origem.
