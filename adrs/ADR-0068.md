# ADR-0068 — Usar Ubuntu Server 26.04 LTS na próxima VPS

Status: Aceito

## Contexto

Em 2026-10-09, o usuário escolheu explicitamente Ubuntu Server 26.04 LTS para a próxima VPS de 8 GB, que substituirá
a VPS atual. O inventário somente leitura da máquina atual registra Fedora Server 34, nftables 0.9.8 e ausência de
Docker; ele não é a plataforma de destino. As notas oficiais confirmam Ubuntu 26.04 LTS como release disponível e
descrevem imagens cloud, mas a página pública da Locaweb consultada ainda lista Ubuntu 24.04 LTS para VPS. A
disponibilidade de uma imagem 26.04 pelo provedor permanece pendente. Esta decisão de destino não comprova provisionamento,
compatibilidade operacional, capacidade ou instalação.

## Decisão

Planejar a migração para uma nova VPS de 8 GB com Ubuntu Server 26.04 LTS. Manter a VPS Fedora atual como ambiente de
origem até uma migração futura explicitamente executada. Os scripts administrativos devem detectar ferramentas e
capacidades reais no host e falhar com orientação quando não forem compatíveis; não declarar compatibilidade com base
somente no nome ou versão do sistema operacional.

## Consequências

- Positivas: o ambiente futuro deixa de ser delimitado pela versão antiga Fedora 34 e corresponde à escolha explícita
  do usuário.
- Negativas ou pendências: a imagem 26.04 precisa ser confirmada com o provedor; migração de dados, serviços, firewall,
  Docker, SSH e operação ainda requer planejamento e provas. Nenhuma instalação ou mudança remota decorre deste ADR.

## Alternativas Consideradas

Manter Fedora 34 como destino: rejeitado pelo usuário ao escolher Ubuntu Server 26.04 LTS para a VPS nova. Não há
registro de avaliação de outros sistemas operacionais.
