# ADR-0071: Usar a imagem LinuxServer para BookStack na fixture

Status: Aceito

## Contexto

A preparação local precisa validar BookStack com arquivos de configuração e uploads persistentes, sem importar dados
reais. O usuário aprovou a imagem LinuxServer como candidata comunitária para essa fixture.

## Decisão

Usar a imagem LinuxServer BookStack fixada por digest, persistir `/config` em volume nomeado e fornecer `APP_KEY` e senha
do banco por arquivos secretos. O segredo compartilhado do banco deve ser byte-exato, sem newline final, para que
MariaDB e o handler `FILE__` do BookStack leiam os mesmos bytes. A conta inicial `admin@admin.com` / `password` criada
em banco vazio deve ser trocada antes de expor uma rota BookStack.

## Consequências

- `/config` preserva configurações e uploads entre recriações do container.
- A chave Laravel precisa permanecer estável para preservar dados criptografados existentes.
- O bootstrap inicial usa uma credencial pública conhecida; a fixture não está pronta para exposição até a troca da
  senha administrativa.
- A decisão cobre a fixture nova e não comprova compatibilidade de dados existentes.

## Alternativas Consideradas

A comparação com outras imagens não foi registrada. Esta escolha documenta a candidata aprovada pelo usuário e os
comportamentos descritos pelo mantenedor da imagem.
