# ADR-0011 — Usar SQLite em memória nos testes da API

Status: Aceito

## Contexto

A suíte HTTP usa fixtures para isolar estado entre testes.

Registro retrospectivo do commit `291a07f` (2025-11-30). O status Aceito descreve adoção observada no código, sem afirmar aprovação formal registrada na época.

Evidências: api/config.py; api/tests/conftest.py.

## Decisão

Usar SQLite em memória por padrão e criar/recriar tabelas diretamente nas fixtures.

## Consequências

- Positivas: Permite testes isolados sem MySQL externo.
- Negativas ou limitações: Não valida migrations nem diferenças específicas do banco utilizado no Compose.

## Alternativas Consideradas

O histórico disponível não registra outras opções avaliadas nem por que teriam sido descartadas. Não é possível reconstruir essa avaliação com segurança.
