# ADR-0039 — Usar KDBX como fonte das credenciais de operação

Status: Aceito

## Contexto

O usuário solicitou que a pipeline integre um banco de senhas KDBX contendo credenciais de banco, VPS e
configurações relevantes.

Escolha alinhada com o usuário durante o planejamento do [ROADMAP](../ROADMAP.md). A implementação é futura;
este registro não afirma que os mecanismos já existem.

## Decisão

Usar um arquivo KDBX externo ao Git como fonte das credenciais de operação. A integração deve consultar apenas as
entradas necessárias, com acesso de leitura; não exportar o cofre inteiro. Definir o adaptador e o fornecimento dos
segredos de runtime no desenho da fase correspondente. O desbloqueio está definido separadamente no ADR-0040.

## Consequências

- Positivas: Centraliza as credenciais no formato solicitado e evita colocá-las nos manifests versionados.
- Negativas ou limitações: Exige resolver disponibilidade do arquivo, permissões, leitura de entradas e entrega dos
  segredos aos containers. Credenciais de runtime precisam continuar disponíveis após o término da pipeline, sem
  manter a senha mestra.

## Alternativas Consideradas

Não foram avaliadas alternativas ao formato KDBX nesta etapa; o formato foi solicitado explicitamente pelo usuário.
