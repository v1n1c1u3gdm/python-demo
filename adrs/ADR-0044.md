# ADR-0044 — Analisar segurança Python com Bandit

Status: Aceito

## Contexto

O gate por comandos precisa analisar problemas comuns de segurança Python além do lint existente. Bandit foi
apresentado na proposta de substituição do Sonar, aceita pelo usuário.

Escolha alinhada com o usuário durante o planejamento do [ROADMAP](../ROADMAP.md). A implementação é futura;
este registro não afirma que os mecanismos já existem.

## Decisão

Incluir Bandit na análise de segurança Python da futura pipeline, executado localmente em container e na VPS. Medir
o código atual e alinhar o tratamento de severidade, confiança e exceções específicas antes de configurar o gate.

## Consequências

- Positivas: Adiciona análise estática especializada sem um serviço permanente.
- Negativas ou limitações: Pode produzir falsos positivos e não detecta todas as falhas de autorização ou de
  comportamento; testes e revisão continuam necessários. Compatibilidade com a versão Python adotada será validada.

## Alternativas Consideradas

Não foram avaliadas alternativas específicas ao Bandit nesta etapa. O Sonar foi considerado como solução
integrada e substituído pelo conjunto CLI conforme o ADR-0038.
