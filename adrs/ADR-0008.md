# ADR-0008 — Evoluir o schema com migrations Alembic

Status: Aceito

## Contexto

Bancos existentes precisam acompanhar mudanças do domínio.

Registro retrospectivo do commit `291a07f` (2025-11-30). O status Aceito descreve adoção observada no código, sem
afirmar aprovação formal registrada na época.

Evidências: api/extensions.py; api/migrations/.

## Decisão

Versionar a evolução do schema com Alembic integrado por Flask-Migrate.

## Consequências

- Positivas: Permite aplicar mudanças de schema de maneira rastreável.
- Negativas ou limitações: Novos campos exigem migrations e validação de dados existentes.

## Alternativas Consideradas

O histórico disponível não registra outras opções avaliadas nem por que teriam sido descartadas. Não é possível
reconstruir essa avaliação com segurança.
