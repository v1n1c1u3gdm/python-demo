# ADR-0035 — Validar Python com Ruff

Status: Aceito

## Contexto

O projeto exige lint Python e ainda não possuía ferramenta configurada.

Escolha alinhada com o usuário nesta conversa. Aceitação da decisão não significa implementação concluída. Evidência do
estado anterior: `AGENTS.md`.

## Decisão

Adotar Ruff para validar código Python e testes, com configuração versionada e execução antes da conclusão e de commits.

## Consequências

- Positivas: Fornece verificação reproduzível.
- Negativas ou limitações: Exige tratar violações existentes e justificar exceções específicas.

## Alternativas Consideradas

Não houve escolha de outra ferramenta; o usuário aprovou Ruff após a proposta. Comparações adicionais não foram
realizadas.
