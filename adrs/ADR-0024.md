# ADR-0024 — Iniciar desenvolvimento em branches semânticas

Status: Aceito

## Contexto

O usuário exige que todo desenvolvimento comece em branch semântica.

Decisão explícita do usuário nesta conversa; formalizada em `AGENTS.md`. Não representa um release.

Evidências: AGENTS.md.

## Decisão

Criar ou selecionar uma branch `<tipo>/<descricao-em-kebab-case>` antes de alterar arquivos de desenvolvimento.

## Consequências

- Positivas: Identifica intenção e isola trabalho das branches principais.
- Negativas ou limitações: Exige verificar estado existente e preservar alterações do usuário.

## Alternativas Consideradas

Não foram registradas outras opções avaliadas pelo usuário nem razões de descarte; não há base para atribuir uma comparação formal.
