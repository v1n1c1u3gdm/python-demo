# ADR-0031 — Usar Vue 3 na SPA

Status: Aceito

## Contexto

A UI usa Vue 2 e o usuário solicitou sua atualização.

Escolha alinhada com o usuário nesta conversa. A migração foi implementada e validada com testes, lint e build.
Evidência do estado anterior: [ADR-0003](ADR-0003.md).

## Decisão

Migrar para Vue 3 e Vue Router 4, preservando rotas e Options API. Esta decisão substitui o
[ADR-0003](ADR-0003.md), preservado como registro histórico.

## Consequências

- Positivas: Atualiza o runtime mantendo a organização das views.
- Negativas ou limitações: Exige adaptação do bootstrap, router e testes.

## Alternativas Consideradas

Manter Vue 2: descartado pelo pedido explícito de migração.
