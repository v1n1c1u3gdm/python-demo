# ADR-0058 — Orquestrar a CI com Woodpecker integrado ao GitHub

Status: Aceito

## Contexto

A Fase 3 precisa acrescentar CI auto-hospedada à infraestrutura da VPS e manter o GitHub como hospedagem do
repositório e dos pull requests. Em 2026-10-04, o usuário escolheu explicitamente Woodpecker integrado ao GitHub.
A migração para Forgejo foi considerada no planejamento e não escolhida. A decisão descreve a arquitetura aprovada;
não afirma que servidor, integração ou webhook estejam instalados.

## Decisão

Usar Woodpecker CI auto-hospedado, conectado ao repositório atual no GitHub. Manter GitHub como sistema de origem de
código e pull requests; não migrar o repositório para Forgejo.

## Consequências

- Positivas: mantém o fluxo existente de contribuição no GitHub e permite hospedar a execução de CI na infraestrutura
  controlada pelo projeto.
- Negativas ou limitações: a operação passa a depender da instalação e manutenção do Woodpecker e de uma integração
  GitHub configurada corretamente. Esta decisão não comprova implantação nem configuração externa.

## Alternativas Consideradas

Migrar o repositório para Forgejo: considerada no planejamento, mas o usuário escolheu manter o GitHub e integrar
Woodpecker a ele.
