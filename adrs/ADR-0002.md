# ADR-0002 — Usar Flask para a API

Status: Aceito

## Contexto

O projeto precisava implementar endpoints HTTP para autores, artigos e perfis sociais. A motivação original da escolha
do framework não foi registrada.

Registro retrospectivo do commit `291a07f` (2025-11-30). O status Aceito descreve adoção observada no código, sem
afirmar aprovação formal registrada na época.

Evidências: api/app.py; api/blueprints/__init__.py.

## Decisão

Implementar a API em Flask com factory e blueprints por responsabilidade.

## Consequências

- Positivas: Favorece registro modular dos endpoints.
- Negativas ou limitações: Mudanças na factory afetam inicialização e comportamento transversal.

## Alternativas Consideradas

O histórico disponível não registra outras opções avaliadas nem por que teriam sido descartadas. Não é possível
reconstruir essa avaliação com segurança.
